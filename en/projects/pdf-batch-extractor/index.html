Batch PDF Extraction

A PDF → HTML → text pipeline that splits body and table extraction across two engines and gates output on three quality checks.

Role
Tooling
Period
2026.09
Stack
Python · PyMuPDF · pdfplumber
Repo
github.com/byte-love/pdf-batch-extractor

Problem

In annual reports, prose and tables interleave; a single engine either mangles tables or shreds paragraphs. Headers and footers polluted output, and a cover page whose company name matched the running header once got deleted entirely.

What I did

  • Used PyMuPDF for prose and pdfplumber for tables, then merged the two results
  • Deduplicated overlapping regions by bounding box
  • Three quality gates: coverage ratio, character density, and outlier checks (caught 152 bogus "0.00" values in one run)
  • Multiple table renderings (Markdown / TSV / plain) plus page anchors for tracing back to the source

Result

  • 240 pages in 45 seconds, coverage 0.9707
  • Quality-gated extraction, suitable for unattended batches
