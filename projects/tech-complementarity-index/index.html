地区间技术互补指数（TACD）

从 2,200 万行专利分类号算 RPCA 与技术联系指数，带全量自检。

角色
数据工程
时间
2026.09
技术栈
Python 3.12 · lxml · multiprocessing · 自研 xlsx 写出
仓库
github.com/byte-love/tech-complementarity-index

问题

沿用旧实现会算不出最新年份的数据（旧快照只到 2024，源数据到 2025），而且旧代码把没校验过的分类号当 IPC 小类写进结果，混入了数千条脏值；最内层循环里逐条打印，是它跑几天的首要原因。

我做的

  • 重写为 Python 流水线：解析 → 计数聚合 → 指标计算，输出省级 / 城市级 / 上市公司三档
  • 并行执行优先用进程池，环境禁掉进程池时自动降级为子进程 + 临时文件
  • 自研 xlsx 写出，替掉通用库的开销
  • 写 selftest.py 做全量对账：各地区之和 = 当年总数、IPC 计数 = 逐条求和、共现对数 = ΣC(k,2)

结果

  • 2,200 万行 100~125 秒跑完，约 14 万行/秒
  • xlsx 写出 20.1 秒 → 2.3 秒（8.7 倍）
  • selftest 全量对账通过，脏 IPC 在前置环节被挡掉
