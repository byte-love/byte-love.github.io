专利质量指标计算流水线

7,945 万行 Excel 的流式解析、并行预聚合与独立校验链。

角色
数据工程
时间
2026.09
技术栈
Python 3.12 · lxml · multiprocessing · 定点整数中间文件
仓库
github.com/byte-love/patent-quality-pipeline

问题

源数据是 60 个 xlsx，单文件最大 37 MB / 100 万行，且多数文件的 max_row 被写成假的 1,000,000（尾部大量空行），常规加载会吃掉大量内存；如果让子进程把行级结果回传父进程，跨进程传输量会大到不可接受。

我做的

  • 不用 pandas / openpyxl，直接 iterparse 流式解析 xlsx 内部 XML（只在行结束时清理节点）
  • 子进程边解析边按（主体, 年份）预聚合，只把预聚合结果回传，传输量缩小几个量级
  • 中间文件用定长定点整数（1e-6）存指标值，避免浮点格式带来的精度争议
  • 另写一条独立校验链：绕开全部中间文件，直接从原始 xlsx 重算并逐格比对输出

结果

  • 读取总行数 7,945 万，8 个分区并行，解析 3.9 分钟、方法一 1.5 分钟
  • 47,926 + 168,194 个格子逐格一致（误差 < 1e-9）
