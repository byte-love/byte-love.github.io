PDF 批量抽取：双引擎 + 质量门禁

正文与表格分引擎处理，带三项质量检查的 PDF → HTML → 文本流水线。

角色
工具开发
时间
2026.09
技术栈
Python · PyMuPDF · pdfplumber
仓库
github.com/byte-love/pdf-batch-extractor

问题

年报类 PDF 正文与表格混排，单一引擎要么表格错行、要么正文被切碎；页眉页脚与封面页会污染抽取结果，封面页的公司全名和页眉完全一样，曾导致整个封面被错误剔除。

我做的

  • 正文用 PyMuPDF、表格用 pdfplumber，分别取长再合并
  • 按 bbox 去重，处理两个引擎重复命中的区域
  • 三项质量门禁：覆盖率、字符密度、异常值检查（一次拦下 152 个「0.00」假值）
  • 支持 Markdown / TSV / 纯文本多种表格形态，以及页码锚点便于回溯原文

结果

  • 240 页 45 秒，覆盖率 0.9707
  • 带质检环节的抽取，比只做转换的脚本更适合无人值守
